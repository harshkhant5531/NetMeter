
# ![Home Screen](assets/images/home.png) NetMeter

**NetMeter** is a Flutter-based mobile application that measures internet speed and displays real-time network statistics such as download speed, upload speed, and ping. The app provides a modern user interface with visual gauges to represent network performance in an intuitive way.

This project demonstrates the implementation of **network speed testing, real-time data visualization, and Flutter UI development.**

```

## 2️⃣ Navigate to Project Folder

```

```

## 3️⃣ Install Dependencies

```

## 4️⃣ Run the Application

```

```

# 📊 How It Works

1. The application sends network requests to test internet performance.
2. It calculates **download and upload speeds**.
3. The results are displayed using **visual speed gauges**.
4. The app also shows **ping and network information**.
